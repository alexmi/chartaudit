# ChartAudit

Hindsight-free scoring for the lines traders draw on charts. ChartAudit reads a marked-up chart screenshot with Meta's Muse Spark, turns each drawn position box and level into exact prices and dates, and scores it only on what price did after the chart was made, compared with algorithmic and random lines.

Built during the Meta Global AI Developer Hackathon, Oct 27 to Nov 4, 2026. Everything in this repository was written during the hackathon.

## Data and rights

* `data/public/`: images from Wikimedia Commons, credited in `data/public/CREDITS.md`. Files in `data/public/cc-by-sa/` are CC BY-SA, and anything derived from them is shared under the same license.
* Synthetic charts are generated by the code here, from random-walk prices with no real edge.
* Third-party screenshots used for private evaluation are never committed; the repo holds only links and labels.

## Setup

```
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
cp .env.example .env   # then add your Meta Model API key
.venv/bin/pytest
```
